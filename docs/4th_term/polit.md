# Требования к сессии

1.  #### Электронная версия конспекта (50 вопросов).
    

-   Должен быть уникальным, а не у всей группы одинаковый. Объем: 1 стр на вопрос  
    Отправить в ТГ до сесси (будет создан чат)

2.  #### Реферат:
    

-   Темы рефератов выбирать так, чтобы у группы были вопросы из всего перечня, а не только из первой части.
-   Общий объем пирмерно 10 стр
-   Введение и заключение не нужны
-   Список использованных источников должен быть не тупо скопированные списки литературы, а ссылки на источники откуда реально брали инфу
-   На титульном листе указать кафедру: Кафедра экономики и управления
-   Шрифт: Timese New Roman 14пт, межстрочный интервал: 1
-   Выравнивание по ширине
-   Реферат должен содержать актуальную информацию
-   Принести просто в файлике, без папки
