# Требования к допуску

## ЛР в moodle №2 и №8

**ЛР №2:**  
Оставляем только моделирование.  
**R<sub>22</sub> номинал изменить, будет:**  
**10кОм + № Варианта \* 0,1кОм**  
_Пример для 15 варианта:_ 10кОм + 15\*0,1кОм = 11,5кОм

**R<sub>24</sub> поменять на 5кОм**  
**Напряжение ЭДС 20V**

В отчете должно быть:

-   Расчет R<sub>1</sub> по формуле
-   Таблица с результатами моделирования
-   Скриншот модели с расчетным R<sub>1</sub> при котором значение выхода равно 0V
-   По результатам внесенным в табличку построить график зависимости Выходного напряжения (PV4) от R<sub>1</sub>

**Пометки к отчету здесь [laba\_2\_titl.docx](/4th_term/el_tech_el/laba_2_titl.docx)**
